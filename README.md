# 爪间小食 · PAW & PANTRY

天然简约风格的中文宠物零食虚拟商城。原生 HTML、CSS 和 JavaScript，无第三方运行依赖、无构建步骤，所有图片均保存在本地。

## 启动预览

安装 Node.js 18 或更高版本后，在当前目录运行：

```powershell
cd 'D:\Pet treats'
node server.mjs
```

浏览器访问 <http://127.0.0.1:5173>。关闭服务时在终端按 `Ctrl+C`。默认仅监听本机，不公开到局域网。端口被占用时，可以指定其他端口：

```powershell
$env:PORT = '5174'
node server.mjs
```

请使用上述 HTTP 地址打开，不要直接双击 `index.html`。账号功能使用 JavaScript 模块和 Web Crypto，需要浏览器允许本地存储。

## 虚拟商城体验

1. 首次进入显示登录页，使用邮箱和密码登录；注册需要昵称、邮箱、密码及电话号码。
2. 右上角“游客访问”可进入首页。游客可以浏览与筛选商品，点击购买时会提示登录或注册。
3. 点击任意商品卡片进入详情，可选择 1–99 件；登录或注册后会继续之前的购买。
4. 填写收件人、电话、所在地区和详细地址，点击“确认地址，生成模拟订单”。不实际付款、不实际发货。
5. “我的订单”可查看当前账号的模拟订单及地址；退出后回到登录页。

账号及订单保存在当前浏览器、当前站点地址的 `localStorage` 中；刷新后保留，清除站点数据会删除这些记录。换浏览器、端口或从 `127.0.0.1` 改为 `localhost` 会使用另一份存储。登录及游客身份保存在当前标签页的 `sessionStorage`，刷新可继续，关闭会话后需重新进入。

这是本地演示流程，建议使用虚构资料和演示专用密码。密码保存为随机盐加 PBKDF2 摘要，不保存明文。没有后端、邮件或短信验证，也不提供跨设备同步；前端访问控制不能替代正式商城的服务端认证。

## 内容与维护

- `index.html`：登录／注册、首页结构、品牌文案、图标及示例说明。
- `styles.css`：配色、排版、响应式布局、焦点样式及减少动态效果的适配。
- `shop.css`：登录、商品详情、结算和订单页面的响应式样式。
- `app.js`：全部 / 狗狗 / 猫咪筛选、移动菜单、Esc 关闭、导航状态更新。
- `shop.js`：页面路由、登录／注册表单、游客引导、商品详情、地址与订单界面。
- `store.js`：浏览器本地账号与订单、输入校验、密码摘要、订单归属和防重复提交。
- `catalog.js`：6 款商品的统一数据来源；价格以整数“分”保存。
- `tests/store.test.mjs`：账号、订单和存储失败的自动化测试。
- `assets/`：本地照片、原创包装插画及 favicon。
- `scripts/create-packaging.mjs`：生成 6 张包装 SVG；修改配色或商品名称后可运行 `npm run assets`。

修改商品名称、文案、分类或价格时编辑 `catalog.js`；金额以分为单位，例如 `2990` 表示 ¥29.90。包装插画中的商品名可通过 `scripts/create-packaging.mjs` 更新。商品卡片、详情和订单金额共用商品数据。

## 验证

```powershell
node --check app.js
node --check shop.js
node --check store.js
node --check catalog.js
node --check server.mjs
node --check scripts/create-packaging.mjs
node --test tests/*.test.mjs
```

浏览器回归步骤：

1. 桌面和手机宽度下，页面无横向滚动，全部图片成功显示。
2. 初始展示 6 款；狗狗 / 猫咪分别展示 3 款；“全部小食”恢复 6 款。
3. Tab 键访问按钮，Enter 或空格激活筛选；筛选按钮选中状态和结果提示同步改变。
4. 手机菜单展开后可通过链接导航；链接跳转后菜单关闭。Esc 关闭菜单并恢复按钮焦点。
5. 页尾“看看所有小食”恢复全部分类并跳转到产品区。
6. 检查锚点不会被顶部导航遮挡；浏览器控制台无脚本错误。
7. 游客购买出现登录提示；注册、登录后保留商品和数量并跳转结算。
8. 错误密码、重复邮箱、无效电话、缺失地址应提示错误；无效内容不能生成订单。
9. 生成订单后刷新仍可查看；退出后不可访问订单，另一个账号看不到当前账号的订单。
10. 通过 Tab、Enter 操作表单和按钮；游客提示框可按 Esc 关闭。

## 示例与素材说明

「爪间小食」为虚构品牌，商品名称、文案和包装为展示用途，不代表真实产品的配料、加工方式、认证或功效。六款商品的价格为人民币示例参考价，不代表实际售价。账号及订单均为本地演示功能，没有实际支付、物流或购物车服务。

`hero.png` 和 `ingredients.png` 使用内置 ImageGen 生成；完整生成提示词记录在 `assets/image-prompts.json`。包装图与图标是项目内原创 SVG，无外部图片、字体或 CDN 请求。
